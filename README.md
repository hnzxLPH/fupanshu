# 复盘鼠 · 学习复盘数据系统

**复盘鼠**是一款面向高中生学习复盘场景的数据分析工具。项目通过表格导入、知识点分析、可视化看板、PDF 报告和 JSON 备份等功能，帮助学生把每一次练习和考试转化为可复盘、可行动的学习证据。

> 正式访问地址：<https://hnzxlph.github.io/>

## 仓库结构

| 目录 | 内容 | 用途 |
|---|---|---|
| `app/` | React + Vite 源码 | 用于继续开发、修改界面和重新构建项目 |
| `release/` | `index.html` 单文件正式版 | 可直接下载或部署，适合比赛展示 |
| `assets/` | 复盘鼠 Logo 等品牌素材 | 保存展示和宣传素材 |
| `sample-data/` | 示例 Excel 数据 | 用于现场演示导入与分析流程 |
| `docs/` | 解说词、研究报告、品牌方案 | 用于答辩、申报和项目介绍 |
| `scripts/` | HTML 打包、Logo 整合、验证脚本 | 用于维护发布版本 |

## 快速使用

如果只是体验网站，请直接打开正式地址：<https://hnzxlph.github.io/>。如果需要离线演示，可以下载 `release/index.html` 后用浏览器打开。

如果需要继续开发，请进入 `app/` 目录安装依赖并启动开发服务器：

```bash
cd app
pnpm install
pnpm run dev
```
