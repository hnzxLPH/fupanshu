复盘鼠是一款面向高中生自主学习、错题管理与学情分析的智能化复盘工具。本项目针对高中生学习记录杂乱、复盘不系统、学情总结不直观、数据难以分析等普遍痛点，设计以标准化Excel台账为核心记录载体，整合每日学情记录、学科错题整理、知识点追踪、周度复盘总结与薄弱点归档功能，构建完整的高中生学习闭环管理体系。系统统一学习记录格式，规范每日学习时长、科目任务、知识漏洞、优先级标记，实现学习过程可视化、漏洞可追溯、成长可量化。
 
项目创新性在于搭建了文件拖拽式智能数据分析网站，用户可一键上传学习台账文件，自动解析学生学习数据，智能筛选高频薄弱知识点、统计错题重复考点、生成个人学情短板分析结果，解决了传统人工复盘效率低、主观性强、总结不精准的问题。
 
本系统操作简单、适配高中备考场景，无需复杂设备，可长期连续记录学情变化，帮助学生精准定位知识漏洞、合理规划复习重点，有效提升自主复盘效率与备考质量。
