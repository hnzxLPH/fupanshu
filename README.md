# 复盘鼠 — 高效学习复盘评测系统

## 项目简介

**复盘鼠**是一款面向全国高中生的智能学习复盘评测系统，旨在帮助学生通过数据驱动的方式深度分析学习过程、识别知识漏洞、制定优化策略。

本项目参加**海南省青少年科技创新大赛**，致力于将企业管理中的"复盘"文化引入教育领域，让每一个学生都成为自己学习的设计师和管理者。

## 核心功能

### 📊 数据解析与导入
- 支持 XLSX 表格上传，自动解析学习数据
- 灵活的字段映射，适配多种数据格式
- JSON 备份导入导出，便于数据迁移和备份

### 📈 智能分析与可视化
- **学科成绩分布**：直观展示各科目成绩情况
- **知识点掌握热力图**：识别薄弱环节
- **学习趋势分析**：追踪学习进度变化
- **薄弱知识点排行**：优先级排序，精准突破

### 🎯 行动建议与优化
- 基于数据的个性化学习建议
- 知识点补强计划
- 学习时间分配优化

### 📄 导出与分享
- PDF 报告生成，支持离线查看
- 数据备份与恢复
- 支持复盘档案管理

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | React 19 + Vite | 现代化的开发体验 |
| **样式系统** | Tailwind CSS 4 + shadcn/ui | 高效的 UI 开发 |
| **数据处理** | SheetJS (xlsx) | 本地 XLSX 解析 |
| **图表展示** | Recharts | 交互式数据可视化 |
| **PDF 导出** | html2canvas + jsPDF | 高保真报告生成 |
| **路由管理** | Wouter | 轻量级客户端路由 |

## 项目亮点

✨ **完全离线可用**：所有功能在浏览器本地执行，无需后端服务  
✨ **单文件部署**：`study-review-standalone-contest.html` 可直接双击打开  
✨ **"复盘鼠"品牌**：可爱卡通形象，提升用户体验  
✨ **数据驱动决策**：将企业管理方法论应用到学生学习中  
✨ **隐私保护**：用户数据完全本地存储，无上传风险  

## 快速开始

### 方式一：直接使用（推荐）
下载 `exported-assets/study-review-standalone-contest.html`，在浏览器中双击打开即可使用。

### 方式二：本地开发
```bash
# 克隆仓库
git clone https://github.com/hnzxLPH/fupanshu.git
cd fupanshu/fpz/study-review-contest

# 安装依赖
pnpm install

# 启动开发服务器
pnpm run dev

# 构建生产版本
pnpm run build
```

### 方式三：使用示范数据
在 `sample-data/` 目录中提供了 `2026高考复盘本示范样本.xlsx`，可直接上传到网站进行演示。

## 使用指南

### 1. 上传数据
点击"上传 XLSX 表格"，选择包含学习数据的 Excel 文件。系统会自动识别字段并进行解析。

### 2. 查看分析
系统会自动生成：
- 学科成绩分布图
- 知识点掌握热力图
- 学习趋势图表
- 薄弱知识点排行

### 3. 获取建议
基于分析结果，系统会提供个性化的学习建议和优化方案。

### 4. 导出报告
点击"导出 PDF"生成完整的学习分析报告，支持离线查看和分享。

### 5. 备份数据
使用"JSON 备份"功能保存分析数据，支持后续恢复。

## 设计理念

本项目融合了以下教育理念：

- **复盘文化**：学习不是单向的知识灌输，而是通过反思和分析来深化理解
- **数据驱动**：用数据说话，让学生看清自己的学习现状
- **个性化学习**：根据每个学生的特点提供定制化的学习方案
- **自我管理**：培养学生的自我认知和自我管理能力

## 马云视角

> 教育的本质，不是灌输知识，而是唤醒智慧。这个项目做的就是这样一件事情——帮助学生看清楚自己的学习地图，用数据驱动的方式来认识自己、改进自己。
